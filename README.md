# Dynamic Island for Windows

윈도우 바탕화면 위에 얹는 글래스 아일랜드입니다. 위쪽의 검은 알약을 누르면 홈으로 펼쳐지고, 음악, Gemini, 라디오가 그 안에서 이어집니다.

## 실행

```bash
npm install
npm run dev
```

개발 서버는 [http://127.0.0.1:4731](http://127.0.0.1:4731) 에서 열립니다. 공개 페이지는 [https://makaiopluto-maker.github.io/dynamic-island/](https://makaiopluto-maker.github.io/dynamic-island/) 입니다. 그 페이지는 화면을 보여주는 정본이고, 서울 FM 중계와 Google 연결, Gemini는 이 컴퓨터에서 서버를 켜거나 설치본을 열어야 합니다.

## 조작

- 알약을 클릭하면 홈이 펼쳐집니다. 바깥을 클릭하거나 가운데 주황 점을 누르면 다시 접힙니다.
- 카드와 아래 독에서 Home, Music, Gemini, Radio로 이동합니다. 독 양쪽의 +는 설정입니다. Google 계정과 알림 허용이 거기 있습니다.
- 음악은 YouTube Music과 Spotify 중에서 고릅니다. YouTube Music은 곡 이름이나 링크를 넣으면 이 창에서 바로 재생합니다. Google 계정이 연결된 복사본은 내 재생목록도 엽니다. Spotify는 이 브라우저의 Spotify 계정으로 재생합니다. 스페이스바로도 재생을 토글합니다.
- Radio는 서울 FM 주파수를 맞추거나 채널을 고릅니다. 검색으로 방송을 더 넣을 수 있습니다.
- Gemini는 아일랜드 안에서 질문하고 답을 받습니다.
- 접힌 뒤에도 재생 중인 방송, 재생 중인 곡, 읽지 않은 메일, 곧 시작하는 일정이 알약에 남습니다.
- `1` `2` `3` `4`는 홈, 음악, Gemini, Radio입니다. `Esc`는 한 단계씩 접습니다.

## 연결된 것들

- **날씨**는 서울 현재 기온, 하늘, 오늘 최고·최저, 앞으로 몇 시간입니다. 독의 Weather를 열면 그 아래에 오늘 일정이 함께 있습니다. 상태 줄의 숫자도 같은 기온입니다.
- **메일**과 **캘린더**는 Google 계정 하나입니다. 연결 전에는 샘플이고, 화면에도 Sample이라고 적혀 있습니다. 연결되면 메일을 열고 보낼 수 있고, 오늘 일정을 보면서 새 일정을 넣을 수 있습니다. 예전에 연결한 계정은 설정에서 Connect again으로 한 번 더 연결합니다. Google Cloud의 리디렉션 경로는 `/api/auth/google/callback` 입니다.
- **사진**은 Google Photos에서 고른 이미지를 보여주고, 이 기기의 사진을 Google Photos에 올립니다. 연결 전에는 이 기기에만 남습니다. 이미 연결한 계정은 Photos가 열리도록 한 번 더 연결합니다.
- **전화**는 브라우저가 연락처를 열어 줄 때 고를 수 있습니다. 데스크톱 Chrome은 이 API가 없습니다.
- **음악**은 YouTube Music 또는 Spotify입니다. YouTube Music은 검색한 곡이나 붙여 넣은 링크를 이 창의 플레이어로 재생합니다. Google 로그인이 되는 복사본에서는 내 재생목록도 열립니다. 이 웹사이트처럼 서버가 없는 화면에서는 메일과 내 보관함 연결 대신 검색 재생을 씁니다. Spotify는 고른 목록이나 붙여 넣은 링크를 이 브라우저의 Spotify 계정으로 재생합니다. 음악과 **라디오**는 시스템 미디어 키에 제목과 재생, 일시정지, 이전, 다음을 넘깁니다.
- **라디오**는 뉴스 채널만 보여 줍니다. YTN, KBS 1라디오, MBC 표준FM, CBS 표준FM, SBS 러브FM, TBS 교통방송입니다. 뉴스 찾기에서 다른 뉴스 채널을 더할 수 있습니다.
- **조명**은 이 PC에서 윈도우 앱으로 열었을 때 모니터 밝기를 바꿉니다. 웹으로 연 복사본은 숫자만 보여 줍니다.
- **Gemini**는 로그인한 사람만 쓸 수 있습니다. 로그인하지 않은 요청은 키를 호출하지 않습니다.
- 프로덕션 서버는 `npm run build` 다음 `npm start` 입니다. 개발 서버의 `/api`도 같은 연결을 씁니다.

## 윈도우 설치 파일

화면 왼쪽 아래의 Windows 버튼이 64비트 설치 파일 `Dynamic-Island-Setup.exe` 를 받습니다. 이미 설치되어 있으면 그 파일을 다시 실행해 제거하거나 다시 설치합니다. Windows 설정의 앱에도 Dynamic Island가 올라갑니다. 설치가 끝나면 검은 알약이 화면 맨 위 가운데에 붙습니다. 다른 창을 켜도 그 위에 남아 있고, 알약 밖은 클릭이 아래로 통과합니다. 알약을 누르면 홈이 펼쳐집니다. 트레이 아이콘에서 다시 보이거나 끝낼 수 있고, 로그인할 때 다시 켜집니다. 모니터 밝기는 이 설치본에서만 바뀝니다.

이 페이지를 연 채로 새 버전이 올라오면 왼쪽 아래에 업데이트 알림이 뜨고, Reload로 새 화면을 불러옵니다. 설치한 윈도우 앱은 시작 때 새 버전을 확인해서 알림을 띄웁니다. 알림을 누르면 창이 앞으로 옵니다.

개발 중에 같은 창을 보려면:

```bash
npm run build
npm run desktop
```
