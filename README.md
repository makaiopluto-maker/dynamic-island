# Dynamic Island for Windows

윈도우 바탕화면 위에 얹는 글래스 아일랜드입니다. 위쪽의 검은 알약을 누르면 홈으로 펼쳐지고, 음악, Claude, 집중 타이머가 그 안에서 이어집니다.

## 실행

```bash
npm install
npm run dev
```

개발 서버는 [http://127.0.0.1:4731](http://127.0.0.1:4731) 에서 열립니다.

## 조작

- 알약을 클릭하면 홈이 펼쳐집니다. 바깥을 클릭하거나 가운데 주황 점을 누르면 다시 접힙니다.
- 카드와 아래 독에서 Home, Music, Claude, Focus로 이동합니다.
- 음악은 재생, 일시정지, 이전/다음, 탐색이 실제로 흐릅니다. 스페이스바로도 재생을 토글합니다.
- Focus의 Start는 25분 타이머를 돌리고, 눈금자를 누르면 1–60분으로 길이를 바꿉니다. 끝나는 시각은 서울 시간입니다.
- Claude의 Edit 탭은 몇 초마다 다음 수정으로 넘어갑니다. Read, Test, Done은 그 세션의 다른 상태입니다.
- 접힌 뒤에도 재생 중인 곡, 진행 중인 집중, 편집 시간, 읽지 않은 메일, 곧 시작하는 일정이 알약에 남습니다.
- `1` `2` `3` `4`는 홈, 음악, Claude, Focus입니다. `Esc`는 한 단계씩 접습니다.

## 연결된 것들

- **날씨**는 서울 현재 기온입니다. 상태 줄의 숫자가 그 값입니다.
- **메일**과 **캘린더**는 Google 계정 하나입니다. 연결 전에는 샘플이고, 화면에도 Sample이라고 적혀 있습니다. 연결되면 받은편지함과 오늘 일정이 들어옵니다. Google Cloud의 리디렉션 경로는 `/api/auth/google/callback` 입니다.
- **사진**은 이 기기의 이미지를 아일랜드에 올립니다.
- **전화**는 브라우저가 연락처를 열어 줄 때 고를 수 있습니다. 데스크톱 Chrome은 이 API가 없습니다.
- **메시지**는 휴대폰 문자를 읽지 않습니다. 집중이 끝나면 알림이 여기 쌓이고, 고른 연락처로 문자를 띄울 수 있습니다.
- **음악**은 시스템 미디어 키에 곡 이름과 재생, 일시정지, 이전, 다음을 넘깁니다.
- 프로덕션 서버는 `npm run build` 다음 `npm start` 입니다. 개발 서버의 `/api`도 같은 연결을 씁니다.
