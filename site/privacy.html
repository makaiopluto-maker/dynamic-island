개인정보처리방침

최종 업데이트: 2026년 11월 23일

Dynamic Island for Windows(“앱”)는 사용자의 Google 계정으로 메일, 캘린더, Google Photos, YouTube 데이터를 가져와 데스크톱에서 보여 줍니다. 이 방침은 어떤 정보를 다루는지 설명합니다.

수집·이용하는 정보

  • Google 로그인으로 받은 계정 식별 정보(이메일 등)와 OAuth 액세스/리프레시 토큰
  • 사용자가 연결한 Google 서비스의 메일, 일정, 사진 메타데이터/미리보기, YouTube 라이브러리·재생 관련 데이터
  • 앱 설정(예: 음량)처럼 기기 로컬에 저장되는 환경 설정

보관 위치

Google OAuth 토큰과 설정은 사용자의 Windows 기기에만 저장됩니다(예: 앱 사용자 데이터 폴더). 저희 서버로 Google 계정 비밀번호를 보내거나 저장하지 않습니다. GitHub Pages에 올라간 웹사이트는 제품 소개과 정책 문서만 제공하며 Google 토큰을 받지 않습니다.

이용 목적

  • 사용자가 요청한 메일·캘린더·사진·음악 기능을 표시하고 제어하기 위해
  • 로그인 상태를 유지하고 앱을 다시 열 때 연결을 복구하기 위해

제3자 제공

앱은 Google API에서 받은 데이터를 광고·판매 목적으로 제3자에게 제공하지 않습니다. 데이터는 Google의 정책과 사용자가 동의한 OAuth 범위 안에서만 Google과 주고받습니다.

Google API 서비스 사용자 데이터 정책

앱의 Google 사용자 데이터 사용은 Google API Services User Data Policy(Limited Use 포함)를 준수합니다.

보관 및 삭제

사용자는 앱에서 Google 연결을 해제하거나 앱을 제거해 로컬 토큰·설정을 삭제할 수 있습니다. Google 계정 보안 설정에서 앱 액세스도 취소할 수 있습니다.
